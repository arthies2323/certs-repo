# Certs Prep

Plataforma mobile-first para preparação de certificações.

## Primeira certificação
AWS Certified Cloud Practitioner (CLF-C02).

## V1
- banco aberto com histórico local
- continuar de onde parou
- questões novas / revisão de erros
- desempenho por domínio
- simulado separado com 65 questões e 90 minutos
- histórico de simulados

A base CLF-C02 utilizada na V1 vem do projeto open-source CloudCertPrep (MIT):
https://github.com/nastaso/cloudcertprep

O conteúdo de prática não é material oficial da AWS.

A arquitetura do repositório será expandida para suportar outras certificações e sincronização em nuvem nas próximas versões.
